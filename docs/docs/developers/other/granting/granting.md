## Parrot access for managed pipelines

In addition to standard connectors, Parrot also manages data pipelines for customers or sets up orchestration for moving data from object stores/data warehouses into Parrot's managed database service. Parrot's dedicated data engineering services help build out everything from basic orchestration to complete data enrichment and custom data pipelines.

To provide access for the Parrot team, your team can grant read access: 

- [Amazon s3](/developers/other/granting/aws-s3-bucket)
- [GCS](/developers/other/granting/gcs-bucket)
- [Google BigQuery](/developers/other/granting/google-bigquery)
- [Microsoft Azure Storage](/developers/other/granting/azure-storage-container)

For more information on how Parrot can help, please contact our team at [contact@statsparrot.com](mailto:contact@statsparrot.com).
