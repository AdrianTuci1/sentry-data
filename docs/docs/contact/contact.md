Parrot has a globally distributed team and we'd love to hear from you—whether you're a customer, prospect, or simply a Parrot enthusiast. There are several ways to get in touch with the Parrot team and engage with the community, which are described below.

## GitHub

Parrot is part of the open source community, and you can find the source code of our Parrot Developer project on GitHub [here](https://github.com/staticlabs/statsparrot). We welcome contributions, but if you simply want to report a bug, file an issue, or request a feature, you can do so on [this page](https://github.com/staticlabs/statsparrot/issues).

## Discord

Curious to see if someone else has encountered an issue before, looking for help getting started, interested in tapping into the collective knowledge of others, or simply want to engage with other members of the Parrot community? Parrot's community can be found on Discord, and we'd love for you to be a part of it! Please click [here](https://discord.gg/2ubRfjC7Rh) to access our dedicated Discord channel.

## Contacting Support
If you'd like to get in contact with the Parrot team directly and/or contact Parrot Support, there are a few different options available.

### Slack channel

If you're an active prospect or customer, you will have access to a dedicated Slack channel with the Parrot team. This ensures we can provide you with individualized responses to your questions or issues, with the fastest response times from our distributed team.

:::info Interested in evaluating Parrot Cloud?

Please let us know and we'd be happy to set up a Slack channel for your team!

:::

### Email

For individuals who prefer a more traditional medium, you can open a support ticket by reaching out to support@statsparrot.com.

### In-app chat

For logged-in users, Parrot provides the ability to ask a question or report an issue to the Parrot Support team directly from within the application via an embedded in-app chat widget. Select your user icon in the top right corner and choose "Contact Parrot support"—a chat widget will appear on your screen!
